# x15Labs GitHub Organisation

> **⚠️ IMPORTANT: This organisation is for AI experimentation only. No code produced here may be deployed to any environment.**

---

## 🤖 About This Organisation

Welcome to the **x15Labs** GitHub Organisation. This space is dedicated exclusively to **experimenting with and evaluating AI tools, models, and code generation capabilities**.

All repositories within this organisation exist solely for research, exploration, and learning purposes.

---

## 🚫 Restrictions & Policies

The following rules apply to **every repository** in this organisation, without exception.

### No Deployments
- Code produced in this organisation **must never be deployed** to any environment
- This explicitly includes, but is not limited to: development, staging, UAT, pre-production, and **production** environments
- Experimental code is not production-ready and has not undergone the necessary review, security, or compliance processes

### No Sensitive or PII Data
- **No personally identifiable information (PII)** must ever be committed, pushed, or stored in any repository
- **No sensitive data** of any kind (financial records, health data, internal business data, customer data, etc.) may be included in any repository or associated resources

### No Secrets or Credentials
- **No secrets** (API keys, tokens, passwords, certificates, private keys, etc.) must ever be stored in any repository — not in code, comments, commit history, issues, pull requests, or anywhere else
- **No environment variables** containing sensitive values may be configured at either the organisation level or the repository level
- **No GitHub Actions secrets or variables** may be added at either the organisation or repository level

### GitHub Actions Disabled
- **GitHub Actions must be disabled** for every repository in this organisation
- No workflows may be created or executed
- No CI/CD pipelines of any kind may be run within this organisation

---

## ✅ Intended Use

This organisation **may** be used for:

- Exploring and evaluating AI code generation tools (e.g., GitHub Copilot, ChatGPT, etc.)
- Experimenting with AI-generated code snippets and patterns
- Learning about AI capabilities and limitations in a safe, isolated environment
- Sharing findings and knowledge within the team

---

## 📋 Checklist for Each Repository

Before creating or contributing to a repository in this organisation, confirm:

- [ ] The code will **not** be deployed anywhere
- [ ] No PII or sensitive data is included
- [ ] No secrets, credentials, or tokens are present
- [ ] No environment variables with sensitive values are configured
- [ ] GitHub Actions is **disabled** for the repository
- [ ] No GitHub Actions secrets or variables are configured

---

## ❓Questions or Concerns

If you have questions about these policies or believe you have identified a violation, please raise it with your team lead or organisation administrator immediately.
